# 문제해결

## `git`, `node`, `npm` 명령을 찾지 못함

설치 후 Terminal 또는 PowerShell을 완전히 닫았다가 다시 엽니다. 그래도 안 되면 환경점검 결과 화면을 강사에게 보여줍니다.

## Claude Code 명령을 찾지 못함

Claude Code 설치를 확인합니다. ChatGPT 데스크톱 앱의 Codex를 사용할 경우 명령줄 대신 앱에서 `프로젝트` 폴더를 엽니다.

## PowerShell에서 스크립트 실행이 차단됨

다음처럼 현재 실행에만 우회 옵션을 사용합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\01-환경점검\check-windows.ps1
```

회사 정책이 계속 차단하면 스크립트를 실행하지 말고 `git --version`, `node --version`, `npm --version`을 각각 확인합니다.

## AI가 파일을 수정하지 못함

- ZIP을 읽기 전용 또는 네트워크 드라이브가 아닌 로컬 폴더에 다시 압축 해제합니다.
- 프로젝트 폴더를 정확히 열었는지 확인합니다.
- `raw-data/`는 원본 보존 폴더입니다. 새 파일은 `wiki/` 또는 `output/`에 만들도록 요청합니다.

## 결과가 자료와 다름

다음처럼 다시 요청합니다.

> 답변에 사용한 파일명과 원문 문장을 보여줘. 서로 다른 수치가 있으면 하나로 합치지 말고 각각의 출처와 문서 작성 시점을 비교해줘.

6부는 선택 과정입니다. 실습을 생략하고 강사의 시연을 본 뒤 GitHub 부분으로 이동합니다.

## 실제 업무자료를 넣어도 되는지 불확실함

넣지 않습니다. 교육 중에는 제공된 가상 자료만 사용합니다. 실무 적용은 조직의 보안·개인정보·자료 공개 기준을 확인한 뒤 별도 환경에서 진행합니다.
