# 교육 전 준비

## 1. 필수 준비

- macOS 또는 Windows 노트북
- Claude Code 또는 ChatGPT 데스크톱 앱의 Codex
- Git
- Node.js 최신 LTS
- Chrome, Edge, Safari 중 최신 브라우저
- 본인 GitHub 계정

Claude Code를 기본 환경으로 진행하지만, ChatGPT의 Codex에서도 같은 파일 중심 방식으로 실습할 수 있습니다.

공식 설치 안내:

- [Claude Code 설정](https://docs.anthropic.com/en/docs/claude-code/getting-started)
- [ChatGPT 데스크톱 앱](https://chatgpt.com/download/)
- [Git](https://git-scm.com/downloads)
- [Node.js LTS](https://nodejs.org/en/download)
- [GitHub 계정 만들기](https://github.com/signup)

## 2. 압축 해제 위치

동기화 폴더나 네트워크 드라이브보다 개인 PC의 로컬 문서 폴더를 권장합니다.

- macOS 예시: `~/Documents/koica-ai-training-starter`
- Windows 예시: `$HOME\Documents\koica-ai-training-starter`

경로가 너무 길거나 회사 보안 프로그램이 쓰기를 막는 폴더는 피합니다.

## 3. 환경점검 실행

macOS Terminal:

```bash
cd ~/Documents/koica-ai-training-starter
sh 01-환경점검/check-macos.sh
```

Windows PowerShell:

```powershell
cd "$HOME\Documents\koica-ai-training-starter"
powershell -ExecutionPolicy Bypass -File .\01-환경점검\check-windows.ps1
```

## 4. 선택 준비

다음 항목은 필수가 아닙니다.

- Obsidian: 생성된 Markdown Wiki를 직접 탐색할 때 사용
- Cloudflare 계정: 선택 과정인 웹 배포 실습에 사용
- Supabase 계정: 선택 과정인 데이터베이스 실습에 사용

Cloudflare Wrangler 실습은 macOS와 Windows 11에서 진행할 수 있습니다. Windows 10 참가자는 이 선택 실습을 생략하거나 시연만 봐도 됩니다.

ChatGPT 데스크톱 앱의 Codex를 쓸 macOS 참가자는 macOS 14 이상이 필요합니다. 그보다 이전 macOS에서는 Claude Code를 사용하거나 강사에게 미리 알립니다.

## 5. 자료 취급

교육 중에는 이 패키지의 가상 자료만 사용합니다. 실제 수원국 정보, 개인정보, 비공개 사업문서, 계약·평가 자료는 실습 폴더에 복사하지 않습니다.
