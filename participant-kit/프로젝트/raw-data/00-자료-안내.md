# 자료 안내

이 폴더의 모든 자료는 교육용으로 만든 가상 데이터입니다.

문서 작성 시점과 작성 목적이 달라 일부 수치와 결정이 서로 다릅니다. 이것은 오류가 아니라 다음을 연습하기 위한 장치입니다.

- 바이너리 문서를 텍스트로 변환하기
- 자료를 parsing하고 indexing하기
- 파일 이름이 아니라 본문으로 찾기
- 출처와 작성 시점을 비교하기
- Lint와 Bookkeeping을 AI에 맡기기
- 객관적 사실과 사용자 작성 관계를 구분하기

가장 최신 내용이라고 추정되더라도 원문 근거 없이 하나의 값으로 통합하지 마세요.
