# A국 카라오주 농촌 식수 접근성 개선 시범사업

이 프로젝트는 KOICA AI·데이터 교육을 위해 만든 완전한 가상 사례입니다. 실제 국가, 기관, 사업, 예산, 인물 또는 내부 의사결정을 나타내지 않습니다.

## 작업 원칙

1. `raw-data/`는 원본이므로 수정하지 않습니다.
2. 구조화한 지식은 `wiki/`에 Markdown으로 저장합니다.
3. 보고서·표·웹페이지 등 최종 결과는 `output/`에 저장합니다.
4. 모든 주장에는 사용한 원문 파일명을 남깁니다.
5. 원문에 적힌 관계와 AI가 추론한 관계를 구분합니다.
6. 자료 사이의 수치나 결정이 충돌하면 임의로 합치지 않습니다.
7. 외부 업로드·배포·GitHub 푸시는 사용자가 명시적으로 요청한 뒤 진행합니다.

## 시작 요청

> 이 프로젝트의 폴더와 파일을 읽고 무엇이 들어 있는지 설명해줘. 아직 파일은 수정하지 말고, 원자료의 형식과 서로 충돌할 수 있는 정보부터 알려줘.
