# KOICA 해외사무소 AI·데이터 활용 교육 — 참가자 패키지

이 패키지는 실습을 위한 하나의 프로젝트 폴더입니다. 안의 사업명, 국가명, 기관명, 수치와 사건은 모두 교육용 가상 자료이며 실제 KOICA 사업이나 내부 문서를 재현하지 않습니다.

## 교육 전에 할 일

1. 이 ZIP을 개인 PC의 로컬 폴더에 압축 해제합니다.
2. `START-HERE.html`을 브라우저로 열고 [00-사전준비.md](00-사전준비.md)를 읽습니다.
3. 운영체제에 맞는 환경점검 스크립트를 실행합니다.
4. 교육 당일 `프로젝트/` 폴더를 Claude Code 또는 ChatGPT의 Codex에서 엽니다.

## 폴더 안내

| 경로 | 용도 |
|---|---|
| `START-HERE.html` | macOS·Windows에서 더블클릭해 보는 시작 안내 |
| `프로젝트/raw-data/` | 분류하지 않고 모아둔 가상 원자료 |
| `프로젝트/wiki/` | LLM이 생성·관리할 Markdown Wiki |
| `프로젝트/output/` | 요약, 표, 웹페이지 등 최종 산출물 |
| `01-환경점검/` | macOS·Windows 준비 상태 확인 |
| `04-실습-프롬프트.md` | 그대로 복사해 시작할 수 있는 요청 예시 |
| `05-단축키와-명령어.md` | 운영체제별 폴더 열기와 Git 명령 |
| `06-문제해결.md` | 교육 시작 전에 막히는 문제 해결 |

## 중요한 원칙

- 실제 업무자료, 개인정보, 비공개 문서를 이 폴더에 넣지 않습니다.
- 원자료는 수정하지 않고 `wiki/`와 `output/`에 새 파일을 만듭니다.
- AI가 추론한 관계와 원문에 명시된 관계를 구분합니다.
- 답변과 Wiki 페이지에는 사용한 원문 파일명을 남깁니다.
- 외부 배포·업로드·공유는 강사가 안내할 때만 진행합니다.
