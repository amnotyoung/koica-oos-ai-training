# 05. 단축키와 명령어

## 프로젝트 폴더 열기

macOS Terminal:

```bash
cd ~/Documents/koica-ai-training-starter/프로젝트
claude
```

Windows PowerShell:

```powershell
cd "$HOME\Documents\koica-ai-training-starter\프로젝트"
claude
```

ChatGPT 데스크톱 앱의 Codex를 사용한다면 앱에서 `프로젝트` 폴더를 선택합니다.

## Git 첫 기록

```bash
git init
git status
git add .
git commit -m "LLM Wiki 첫 버전"
```

`git add .` 전에 실제 업무자료나 비밀정보가 없는지 확인합니다. 원격 저장소 생성과 푸시는 강사의 안내 뒤에 진행합니다.

## 선택: Cloudflare Pages 직접 배포

```bash
npx wrangler pages deploy <완성폴더>
```

이 명령을 실행하면 계정 로그인과 프로젝트 이름 입력이 추가로 필요할 수 있습니다. Windows 10 참가자는 이 선택 실습을 건너뛰어도 됩니다.

## Obsidian으로 Wiki 보기

Obsidian에서 `프로젝트/wiki/` 폴더를 Vault로 열면 Markdown 페이지와 링크 관계를 직접 탐색할 수 있습니다. Obsidian이 없어도 실습에는 문제가 없습니다.
